## Project Overview

Flipkart-Clone is a single-page static replica of the Flipkart.com homepage. It recreates the header, search bar, navigation, banner carousels, and product category sections using only HTML and CSS, with no backend or JavaScript logic involved.

## Features

- **Landing Page Layout:** Recreation of Flipkart's homepage structure (header, nav bar, banners, category cards).
- **Static Styling:** Pure CSS layout for the homepage sections.
- **Static Assets:** Local images used to mirror the original product/category imagery.

## Tech Stack

- **Frontend:** HTML5, CSS3

## Folder Structure

```bash
Flipkart-Clone/

```

## Installation Guide

### Prerequisites

- A modern web browser
- (Optional) A local static server such as VS Code's "Live Server" extension

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/rajesh-ranjan-git/Flipkart-Clone.git
   cd Flipkart-Clone
   ```

2. Open `index.html` directly in your browser, or serve the folder with a local static server:

   ```bash
   npx serve .
   ```

## Usage Instructions

1. Open the page in your browser to view the recreated Flipkart landing page.
2. Scroll through the header, banner, and category sections to see the layout.
